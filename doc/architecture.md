# Architecture — Wedding Invitation Website

## Огляд
Односторінковий статичний сайт-запрошення на весілля. Без бекенду, без бази даних — вся логіка виконується на клієнті (у браузері).

## Стек
- **HTML5** — розмітка, одна сторінка (`index.html`)
- **CSS3** — стилі, адаптивна верстка (mobile-first, оскільки більшість гостей відкриють з телефону)
- **Vanilla JavaScript** — без фреймворків, для:
  - зворотного відліку до дати весілля
  - генерації посилання/файлу "Додати в календар"

## Структура файлів
```
/
├── index.html          # вся розмітка сторінки
├── style.css           # стилі (mobile-first, картка 480px по центру)
├── index.js            # привітання з ?guest=, таймер, кнопка "Додати в календар"
├── wedding.ics         # статичний календар: церемонія 16:00 + вечеря 17:00
├── favicon.ico         # 32×32, згенерований з assets/icons/favicon-32.png
├── assets/
│   └── images/
│       ├── couple.jpg          # оригінал фото (не використовується на сайті)
│       ├── couple.webp         # оптимізоване фото пари (1000×1500)
│       └── toast-divider.webp  # ілюстрація-розділювач
│   ├── icons/                  # favicon 16/32, apple-touch 180, 192, 512 (майстер)
│   └── music.m4a               # фонова музика (AAC 128 kbps)
└── CNAME                # (опційно) якщо підключається власний домен
```

## Персональне привітання
Ім'я гостя передається у посиланні: `?guest=Діма`, `?guest=Діма&Таня` або
`?guest=Оля,Іван,Петро` → "Оля, Іван та Петро!". Без параметра — "Дорогі гості!".

## Ключові функції

### 1. Додати в календар
Без бібліотек, двома способами:
Пряме посилання на `.ics` телефони **завантажують файлом** замість того, щоб
відкрити календар, тому кнопка розгортає вибір із трьох варіантів:
- **Google Календар** → `https://calendar.google.com/calendar/render?action=TEMPLATE&text=...&dates=...`
  (на Android відкриває застосунок)
- **Apple Календар** → `webcal://` на той самий `wedding.ics`; iOS та macOS
  віддають таке посилання одразу в Календар, а не в завантаження
- **Інший застосунок** → звичайне завантаження `wedding.ics` (Outlook тощо)

### 2. Локація
- Посилання на Google Maps: `https://maps.google.com/?q=lat,lng`
- Або вбудована карта через `<iframe>` (embed-посилання з "Поділитися" в Google Maps, без API-ключа)

### 3. Таймер зворотного відліку
Проста функція на `setInterval`, рахує різницю між поточним часом і датою весілля.

## Хостинг і деплой
- **Хостинг:** GitHub Pages
- **Деплой:** `git push` у гілку `main` (або `/docs`), автоматичне оновлення сайту
- **Домен:** `username.github.io/repo-name` за замовчуванням; власний домен підключається через файл `CNAME` + DNS-налаштування
- **HTTPS:** увімкнений автоматично

## Обмеження
- Немає серверної логіки (форми йдуть через сторонні сервіси)
- Немає бази даних — усі дані "зашиті" в HTML/JS напряму
## Фонова музика
Вмикається за замовчуванням. Мобільні браузери забороняють автозапуск звуку
до першої взаємодії, тому `index.js` одночасно пробує запустити відтворення
одразу **і** слухає перший дотик/клік, доки відтворення справді не почнеться.
Кнопка в кутку вимикає музику; явне «вимкнено» запам'ятовується в
`localStorage` і при наступному відкритті музика сама не стартує.
